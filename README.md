# Research OS

대학원생을 위한 한국어 중심의 개인 연구 관리 웹 앱입니다. 각자 자신의 Mac에서 독립적으로 실행하며 다른 사용자의 데이터와 동기화하지 않습니다.

## 주요 기능

- 프로젝트 대시보드와 프로젝트 정보 수정
- 논문 라이브러리, PDF 읽기, 메모, 읽기 잔디
- 미팅 기록, 할 일, 연구 캘린더
- 미정 기록을 구체화하는 검토할 항목
- AI 연결 시 Research Agent 질문과 등록 제안
- Crossref 외부 논문 검색

## 실행

macOS, Python 3.9 이상이 필요합니다. ZIP을 압축 해제하거나 저장소를 내려받아 폴더에서 실행하세요.

```sh
zsh start.command
```

브라우저에서 http://127.0.0.1:8090 에 접속합니다. 종료는 실행 중인 터미널에서 Control+C입니다. 처음 실행할 때 의존성 설치를 위한 인터넷 연결이 필요합니다.

PDF 기능에는 Poppler의 pdftotext, pdfinfo, pdftoppm이 필요합니다. Windows 직접 실행 및 GitHub Pages 단독 실행은 지원하지 않습니다. 자세한 준비·실행 방법은 [시작 안내](README-START-HERE.txt)를 확인하세요.

## 데이터와 개인정보

이 저장소에는 공통 예시 데이터만 포함합니다. 개인 논문·PDF·로그인 정보·API 키는 포함하지 않습니다. 실행 후 생성되는 data/와 브라우저 저장소의 기록은 사용자 본인이 관리합니다. AI를 사용하려면 본인의 계정 또는 API 키를 연결해야 합니다. AI 질문 시 선택한 자료가 AI 제공자에게, 외부 논문 검색 시 검색어가 Crossref에 전달됩니다.

기록의 일부는 브라우저에만 저장되므로 브라우저 데이터를 지우지 않도록 주의하고 중요한 자료는 별도로 백업하세요. 개인용 MVP이며 공개 인터넷 서버 배포를 전제로 하지 않습니다.

## 사용 조건

개인·비상업적 사용을 허용하는 소스 공개 프로젝트이며, 오픈소스 라이선스를 적용하지 않았습니다. 재배포·상업적 이용에는 별도 허락이 필요합니다. 상세 범위는 [사용 조건](LICENSE.txt)을 확인하세요.
