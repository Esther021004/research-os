Research OS 시작 안내

이 저장소는 Mac/Windows 공용 소스입니다. 각자 컴퓨터에서 빈 연구 공간으로 시작합니다.
Mac: Python 3.10 이상을 준비하고 start.command를 실행하세요.
Windows: Python 3.10 이상을 준비하고 start-windows.bat를 실행하세요.
PDF 기능: Poppler의 pdftotext, pdfinfo, pdftoppm 도구가 필요합니다.
브라우저 주소: http://127.0.0.1:8090
실행 중 터미널을 열어두세요. 종료: Ctrl+C.

자세한 설치 안내, 기능, 지원 범위는 README.md를 읽어주세요.
Windows 실기기 검증은 아직 하지 않았습니다. 이 저장소에는 설치형 앱이 포함되지 않습니다.
개인 기록과 로그인 정보가 생성되는 data-release 폴더는 공유하지 마세요.
프로젝트/할 일/미팅 등은 브라우저에도 저장됩니다. 중요한 기록은 별도로 백업하세요.
