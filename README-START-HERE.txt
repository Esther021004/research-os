Research OS — 독립 실행용 공유본 (Mac)

1. 무엇이 들어 있나요?
프로젝트, 논문 라이브러리, 미팅, 연구 캘린더, 할 일, 검토할 항목,
Research Agent를 제공하는 로컬 웹 앱입니다.
앱 코드와 공통 예시 데이터만 포함했습니다. 배포자의 개인 기록, PDF,
데이터베이스, 로그인 정보, API 키는 포함하지 않았습니다.
다른 사람의 앱과 동기화하거나 배포자의 컴퓨터에 연결하지 않습니다.

2. 준비와 실행
- macOS와 Python 3.9 이상이 필요합니다. Windows 직접 실행은 지원하지 않습니다.
- ZIP을 완전히 압축 해제한 후 Research-OS 폴더를 원하는 곳에 둡니다.
- start.command를 실행합니다. 처음에는 인터넷으로 Python 의존성을 설치합니다.
- 실행 권한 문제라면 터미널에서 해당 폴더로 이동하여 아래 명령을 실행합니다.
  zsh start.command
- 터미널을 열어 둔 채 브라우저에서 http://127.0.0.1:8090 을 엽니다.
- 종료할 때 터미널에서 Control+C를 누릅니다.
- index.html만 더블클릭하면 저장 및 서버 기능이 제대로 동작하지 않습니다.
- 이미 8090 포트를 사용하는 앱이 있으면 해당 서버를 먼저 종료해야 합니다.

3. PDF 기능 준비
PDF 텍스트 추출과 뷰어에는 Poppler의 pdftotext, pdfinfo, pdftoppm이 필요합니다.
Homebrew를 사용 중이라면 터미널에서 brew install poppler로 설치할 수 있습니다.
설치 전에도 일반 기록 관리 기능은 사용할 수 있습니다.

4. AI 및 외부 검색
일반 기록, 미정 항목 저장, 수동 편집에는 AI 연결이 필요하지 않습니다.
Crossref 논문 검색에는 인터넷이 필요하며, 검색어만 Crossref로 전달합니다.
Crossref에 등록되지 않은 논문은 검색 결과에 없을 수 있습니다.
PDF 확보나 원문 분석은 검색과 별도입니다.

AI를 사용하려면 화면 상단 AI 연결 설정에서 자신의 계정/연결 방식을 설정하세요.
ChatGPT 로그인 지원 여부는 계정 권한과 제공 서비스 상태에 따라 다릅니다.
API 키 방식을 선택한다면 자신의 OPENAI_API_KEY를 서버 실행 환경에 설정해야 합니다.
API 사용에는 본인 계정의 비용/한도가 적용될 수 있습니다.
비밀번호나 키를 다른 사람에게 전달하거나 앱 코드에 적어 공유하지 마세요.
AI 질문 시에는 선택한 자료와 질문이 AI 제공자에게 전달됩니다.
AI 생성 내용은 원문과 대조하고, 저장 제안은 확인 후 실행하세요.

5. 데이터 저장 위치와 주의점
- 논문/PDF: 실행 폴더 아래 data/에 새로 생성됩니다.
- 로그인 정보: data/auth/에 저장됩니다. 이 폴더를 공유하지 마세요.
- 프로젝트 설정, 미팅, 일정, 할 일, 검토 기록 등: 현재 브라우저의 로컬 저장소.
- 브라우저 데이터를 지우거나 다른 브라우저를 쓰면 로컬 기록이 보이지 않을 수 있습니다.
- 같은 컴퓨터/브라우저에서 같은 127.0.0.1:8090 주소로 여러 복사본을 실행하면
  브라우저 저장소를 공유합니다. 복사본별 분리가 필요하면 별도 브라우저 프로필을 사용하세요.
- 처음 보이는 연구명/논문/할 일은 예시이며 실제 개인 연구 결과가 아닙니다.
- 앱은 개인 연구용 MVP입니다. 중요한 자료의 유일한 보관 수단으로 쓰지 마세요.
- 외부 폰트 서비스에 연결할 수 있으며 오프라인에서는 기본 글꼴로 표시될 수 있습니다.
- 인터넷 공개 서버로 배포하지 마세요. 현재 서버는 본인 컴퓨터의 로컬 접속용입니다.

6. 다시 공유할 때
재배포에는 별도 허락이 필요합니다. 다른 사람에게는 공개 저장소 주소를 안내하세요.
실행 후 생성된 data/, .venv/, 인증 파일, PDF와 본인의 기록은 공유하면 안 됩니다.

검증 범위
코드 문법과 기존 자동 테스트, ZIP 구성 및 민감 데이터 제외 여부를 점검했습니다.
새 Mac에서의 최초 설치, 외부 검색, 사용자 계정의 AI 로그인은 별도 환경에서 검증이 필요합니다.
