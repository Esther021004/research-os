# Research OS

**흩어진 연구를, 하나의 흐름으로.**

대학원생을 위한 한국어 중심의 개인 연구 관리 도구입니다. 프로젝트·논문·미팅·할 일·일정을 연결하고, 필요한 경우 AI를 연결해 논문 분석과 기록 기반 질문을 사용할 수 있습니다.

현재는 각자 컴퓨터에서 사용하는 **소스 실행 버전과 Mac 앱 테스트 버전**입니다. 설치 없이 접속하는 온라인 웹서비스는 제공하지 않습니다.

## 왜 만들었나요?

석사 과정을 보내면서 개인 연구와 여러 프로젝트, 미팅을 함께 진행하다 보니 주제마다 해야 할 일을 관리하는 데 어려움을 느꼈습니다. 자료를 조사하다 발견한 논문도 “나중에 읽어야지” 하고 넘기기 쉬웠습니다.

단순한 할 일 목록을 넘어, 지금 어떤 연구를 하고 있고 어디까지 진행했는지, 무엇을 읽어야 하는지, 미팅에서 무엇을 결정했는지를 한곳에서 확인하고 싶었습니다.

Research OS는 **“그래서 지금, 어떤 연구의 무엇을 해야 하지?”**라는 질문에 답하기 위해 만들었습니다. 완성된 계획이 아니어도 먼저 기록하고, 나중에 구체화할 수 있는 개인 연구 공간을 목표로 합니다.

## 어떤 기능이 있나요?

| 영역 | 기능 |
| --- | --- |
| 대시보드 | 프로젝트, 할 일, 읽는 논문과 논문 읽기 잔디 확인 |
| 프로젝트 | 생성·정보 수정·색상 구분, 텍스트 Workflow, 연결된 논문·할 일·미팅 |
| 논문 라이브러리 | 수집·외부 검색·PDF 읽기·분석·목차·메모·읽기 관리 |
| 미팅 | 프로젝트별 기록, 전사문·요약·결정 사항 작성, 프로젝트 화면과 연결 |
| 캘린더·할 일 | 일정 등록, 할 일 마감일과 미팅 날짜 표시 |
| 검토할 항목 | 거친 기록을 미정으로 담고 종류·프로젝트·날짜를 확인하여 등록 |
| Research Agent | 선택한 연구 기록 기반 질문, 논문·일정 등록 제안, 외부 검색 진입 |

## 논문 관리: 한 편을 읽고 활용하기까지

### 1. 수집과 서지정보

- 제목·링크를 빠르게 저장하거나 PDF를 업로드합니다.
- Crossref에서 제목·DOI로 검색하고 후보의 제목·저자·연도·DOI를 확인해 등록합니다.
- DOI 정보 조회와 수동 서지정보 수정을 지원합니다.
- 이미 저장한 DOI·제목은 기존 항목을 안내해 중복을 방지합니다.
- 프로젝트를 정하지 않은 논문은 기타·미분류로 보관할 수 있습니다.

외부 검색은 Crossref의 등록 범위에 한정됩니다. 검색은 원문 확보나 PDF 자동 다운로드와 다르며, 원문 분석은 별도로 진행합니다.

### 2. 논문의 구조 파악

원문 PDF나 본문을 준비하고 **AI 분석·모식도·목차 생성** 버튼을 누릅니다.

- 논문의 입력·방법·결과 등 실제 내용에 따른 프레임워크 모식도
- 원문에서 파악한 목차와 페이지 정보
- 모식도 노드별 근거 페이지·문장 확인
- 추출된 원문과 인용문 일치 여부 확인

AI 결과는 틀리거나 누락될 수 있으므로 원문과 함께 검토해야 합니다. 제목·링크만으로 원문 전체를 읽지 않습니다. 스캔 PDF를 위한 OCR은 내장되어 있지 않습니다.

### 3. 구조를 직접 수정

- 프레임워크와 목차를 편집합니다.
- 섹션 제목·페이지 정보를 보완합니다.
- 새 분석을 확인한 뒤 적용하고, 보관된 이전 구조를 복원할 수 있습니다.
- AI 없이 직접 목차를 입력해서 읽기 관리를 시작할 수 있습니다.

### 4. 원문 읽기와 진행률

- 목차에서 연결된 PDF 페이지로 이동합니다.
- 마지막 읽던 페이지에서 다시 시작합니다.
- 섹션별 읽음 체크로 진행률을 관리합니다.
- 읽을 논문·읽는 중·완독 상태와 읽기 목적을 기록합니다.
- 중요한 섹션에는 다시 볼 표시를 남깁니다.

페이지 번호는 PDF 파일 기준이며 인쇄된 쪽수와 다를 수 있습니다. 진행률은 읽은 시간이나 페이지 열람을 추적한 값이 아니라 사용자가 체크한 목차 기준입니다.

### 5. 페이지에 연결된 메모·하이라이트

- 문장을 선택해 인용과 메모를 저장합니다.
- 페이지 전체에 질문·해석·기억할 점을 기록할 수 있습니다.
- 메모에서 원문 페이지로 돌아갑니다.
- 제목뿐 아니라 작성한 메모에서도 검색합니다.

### 6. 검색·정리·내보내기

- 태그·컬렉션·프로젝트·읽기 상태로 자료를 정리합니다.
- BibTeX, 논문 목록, 읽기 메모를 내보냅니다.
- 불필요한 논문은 확인 후 라이브러리에서 삭제할 수 있습니다. 현재 업로드 PDF 파일은 로컬에 보존됩니다.

### 7. 논문 읽기 잔디

최근 12주의 읽기 기록을 대시보드 위젯에서 확인합니다. 프로젝트별 색상과 하루에 기록한 서로 다른 논문 수에 따른 농도로 표시합니다. 같은 날 여러 프로젝트의 논문을 읽으면 해당 칸을 비율로 나눕니다.

목차 읽음 체크 또는 수동 읽기 기록으로 집계하며, PDF를 열기만 한 경우는 포함하지 않습니다. 상세 기록 추가·수정은 논문 라이브러리에서 합니다.

## 어떻게 사용해볼 수 있나요?

이 저장소의 **Code → Download ZIP**으로 최신 Mac/Windows 공용 소스를 받을 수 있습니다. 압축 해제 후 Mac에서는 `start.command`, Windows에서는 `start-windows.bat`를 실행하세요. 필요한 환경은 아래 안내를 참고하세요. 자세한 소개는 [소개 문서](docs/intro.html)에 있습니다(HTML을 내려받아 브라우저로 열 수 있습니다).

릴리스가 게시되면 [GitHub Releases](https://github.com/Esther021004/research-os/releases)에서 운영체제에 맞는 ZIP을 받습니다. 해당 파일이 없다면 아직 게시되지 않은 상태입니다.

| 파일 | 실행 방식 | 지원 상태 |
| --- | --- | --- |
| `Research-OS-macOS-Source.zip` | 소스 → 로컬 서버 → 브라우저 | macOS 소스 실행 |
| `Research-OS-Windows-Source-Preview.zip` | 소스 → 로컬 서버 → 브라우저 | 호환 코드 포함, Windows 실기기 미검증 |
| `Research-OS-Mac-Intel-Preview.zip` | `Research OS.app` 실행 | Intel용 테스트 빌드, 다른 Mac 미검증·Apple 미공증 |

각 ZIP 안의 **시작하기.txt**를 먼저 읽어주세요. Mac 앱은 포함 라이브러리·시각 자산의 배포 조건 확인이 남아 있어 공개 배포 최종본이 아닙니다. Apple Silicon 지원을 보장하지 않으며 Windows 앱(.exe)은 제공하지 않습니다.

### Mac 소스

1. ZIP을 압축 해제합니다.
2. Python 3.10 이상을 준비합니다. PDF 기능에는 Poppler의 `pdftotext`, `pdfinfo`, `pdftoppm`이 필요합니다.
3. `start.command`를 실행합니다. 터미널에서는 다음과 같이 실행할 수 있습니다.

```sh
zsh start.command
```

브라우저가 열리지 않으면 `http://127.0.0.1:8090`에 접속합니다. 실행 중 터미널을 열어 두고, 종료할 때 Control+C를 누릅니다. 첫 실행은 라이브러리를 내려받기 위한 인터넷 연결이 필요합니다.

### Windows 소스

1. ZIP을 압축 해제하고 Python 3.10 이상을 설치합니다.
2. `start-windows.bat`를 실행합니다.
3. PDF 기능을 쓰려면 Windows용 Poppler 실행 파일과 필요한 DLL을 안내에 따라 준비합니다.
4. 브라우저에서 사용하고, 종료할 때 터미널에서 Ctrl+C를 누릅니다.

Windows용 실행 파일·파일 잠금 처리를 포함했지만, 실제 Windows에서 PDF·로그인까지 검증한 버전은 아닙니다.

### Mac 앱

압축 해제 후 `Research OS.app`을 응용 프로그램 폴더로 옮겨 실행합니다. Python·PDF 도구를 따로 준비하는 소스 실행 과정은 필요하지 않습니다. 출처를 확인할 수 없거나 보안 경고의 의미를 알 수 없다면 실행을 중단하고 문의하세요.

## 처음에는 무엇을 하면 되나요?

새 사용자는 빈 연구 공간으로 시작합니다.

1. 첫 프로젝트를 만들고 이름·설명·색상을 정합니다.
2. 논문을 추가하고 읽기 목적·목차·메모를 남깁니다.
3. 할 일에 마감일을 지정해 캘린더에서 확인합니다.
4. 미팅록을 프로젝트와 연결합니다.
5. 필요할 때 AI를 연결합니다.

## AI와 비용

기본 관리 기능에 AI는 필수가 아닙니다. AI 분석·대화를 쓰려면 각자 앱이 지원하는 연결 방식을 설정해야 하며 제공자별 이용 한도·요금이 적용될 수 있습니다.

AI 질문은 동의한 범위의 기록을 선택한 제공자에게 전달합니다. PDF 분석은 추출된 원문을 전송하는 별도 기능입니다. 외부 검색은 검색어를 Crossref에 전달합니다. 미정 기록 분류는 보수적인 문구 규칙이며 모든 입력을 AI가 이해하는 기능은 아닙니다.

## 저장과 개인정보

- 전달용 패키지에는 개인 기록·PDF·로그인 정보·예시 데이터 파일을 넣지 않았습니다.
- 소스 버전의 논문·PDF·인증 정보는 실행 폴더의 `data-release`에 저장합니다.
- 프로젝트·할 일·미팅·일정 등은 현재 브라우저 저장소에 저장합니다.
- Mac 앱은 사용자 `Library/Application Support/Research OS`의 전용 영역을 사용합니다.
- 사용자가 같은 컴퓨터에서 이미 사용했다면 자신의 기록이 다시 보일 수 있습니다.
- 사용자 사이, 앱과 소스 사이, 다른 브라우저 사이에 데이터가 자동 공유되거나 동기화되지는 않습니다.
- 사용한 폴더 전체를 다시 공유하지 마세요. 중요한 기록은 브라우저 저장소와 파일 저장 영역을 구분해 백업하세요.

## 현재 범위

개인 연구용 MVP입니다. 클라우드 협업·외부 캘린더 동기화·자동 음성 전사·OCR은 제공하지 않습니다. 프로젝트 Workflow 생성은 텍스트 분리 규칙 기반이며 논문 AI 분석과 다릅니다. GitHub Pages에는 소개 문서를 게시할 수 있지만, 현재 Python 서버 기능을 그대로 실행할 수는 없습니다.
